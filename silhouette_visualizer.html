What is the Silhouette Coefficient?

The silhouette coefficient measures how well each point fits within its cluster:

  • +1: Point is perfectly clustered (far from other clusters)
  • 0: Point is on the boundary between clusters
  • -1: Point is likely in the wrong cluster

Formula: For each point i: s(i) = (b(i) - a(i)) / max(a(i), b(i))

  • a(i): Average distance to points in same cluster
  • b(i): Average distance to points in nearest other cluster
