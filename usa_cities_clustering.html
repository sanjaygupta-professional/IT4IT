Hierarchical Clustering Information

Agglomerative Hierarchical Clustering is a bottom-up approach:

  1. Start with each city as its own cluster
  2. Find the two closest clusters based on geographic distance
  3. Merge them into a single cluster
  4. Repeat until reaching the desired number of clusters

The dendrogram (right) shows the hierarchy of merges, where the height represents the distance at which clusters merged.
